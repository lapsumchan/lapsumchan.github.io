Notation

Each chapter defines its symbols where they enter the argument. This reference connects the recurring objects; a clearly stated local convention takes precedence.

Symbol Meaning and convention
TT, CC Event and censoring times, measured from the declared time origin in the same units. These are random times; censoring does not reveal the eventual event time.
X=min(T,C)X=\min(T,C), Δ\Delta Observed follow-up and event indicator, Δ=𝟏{T≤C}\Delta=\mathbf1\{T\leq C\}. They remain random in the sampling model; their recorded values are fixed when evaluating a likelihood. The regression bridge uses UU for the same follow-up quantity to distinguish it from a design matrix.
tt, τ\tau A time argument and a specified reporting horizon. Their units match those of TT.
S(t)S(t), F(t)F(t) Survival probability P(T>t)P(T>t) and event-time distribution P(T≤t)P(T\leq t). Both are dimensionless.
λ(t)\lambda(t), H(t)H(t) Instantaneous hazard and cumulative hazard. Hazard has units of inverse time; cumulative hazard is dimensionless. The inference book’s penalty λ\lambda is a separate, explicitly local use.
Yi(t)Y_i(t), Ni(t)N_i(t) At-risk indicator and event-counting process. Here YY describes observation at risk, rather than a regression response.
tjt_j, yjy_j, djd_j Distinct ordered event time, risk-set count and event count at that time. Counts are dimensionless.
ziz_i, β\beta, pp Predictor and coefficient columns of dimension pp, where pp counts slopes and excludes the intercept. Cox regression has no intercept; β𝖳zi\beta^\mathsf{T}z_i is a scalar. The Cox model has no separately identifiable intercept: the baseline hazard absorbs it.
λ0(t)\lambda_0(t), H0(t)H_0(t), S0(t)S_0(t) Baseline hazard, cumulative hazard and survival at the specified reference predictor values. They are not marginal population summaries.
LL, ℓ\ell, UU Likelihood, log likelihood and score when defined with a parameter argument. Elsewhere LiL_i is an entry time; in the regression bridge UiU_i is follow-up. Arguments and scope distinguish these uses.
JJ, λk(t)\lambda_k(t), Fk(t)F_k(t) Event cause, cause-specific hazard and cumulative incidence for cause kk. A competing event changes the probability target.
VjV_j, V̂db\widehat V_{\mathrm{db}} VjV_j is the p×pp\times p weighted covariate covariance within Cox risk set jj. The inference book uses V̂db\widehat V_{\mathrm{db}} for the estimated covariance of debiased slope estimates. These matrices describe different objects.
Φ\Phi Standard normal CDF, used after the relevant standardization and normal-approximation assumptions are stated.

When a matrix is used, observations occupy rows and predictors occupy columns. The Cox design is n×pn\times p without an intercept; AFT regression uses the augmented vector vi=(1,zi𝖳)𝖳v_i=(1,z_i^\mathsf{T})^\mathsf{T} and an n×(p+1)n\times(p+1) design. A coefficient’s units compensate for its predictor so that a linear predictor is dimensionless. Code uses dot-separated author-defined R names; package APIs retain their own spelling.
