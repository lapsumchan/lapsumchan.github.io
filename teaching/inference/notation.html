Notation

Each chapter defines its symbols where they enter the argument. This reference connects the recurring objects; a clearly stated local convention takes precedence.

Symbol Meaning and convention
nn, ii Number of observations and observation index, i=1,…,ni=1,\ldots,n. The observation unit is specified with the model.
XiX_i, xix_i; DnD_n, dnd_n A random observation and its realized value; a random sample and its observed realization. In the opening binary model, XiX_i is an event indicator.
pp An event probability in the binary chapters. In connected regression sections, pp counts predictor slopes and excludes the intercept.
θ\theta, θ̂\widehat\theta A model parameter and a data-dependent estimate. The model specifies their dimensions.
ℒ(θ;d)\mathcal L(\theta;d), ℓ(θ;d)\ell(\theta;d) Likelihood and log likelihood with observed data held fixed. Decision loss is the separately defined L(θ,a)L(\theta,a).
aa, δ\delta, R(θ,δ)R(\theta,\delta) An action, a data-dependent action rule and its repeated-sampling expected loss. A prediction and an action are different objects.
π\pi, π(θ∣d)\pi(\theta\mid d) Prevalence in the screening example; a prior or posterior density in Bayesian sections. In logistic regression, πi\pi_i denotes a conditional event probability. Arguments and scope distinguish these uses.
β\beta, β0\beta_0, β+\beta_+ Regression slopes form a p×1p\times1 column β\beta. The intercept is β0\beta_0; the augmented column β+=(β0,β𝖳)𝖳\beta_+=(\beta_0,\beta^\mathsf{T})^\mathsf{T} has p+1p+1 entries. Beta-prior shapes and test-power functions retain their explicitly local meanings.
XX, X+X_+ In regularized regression, XX is the centered n×pn\times p slope design. In ordinary regression, X+X_+ is the n×(p+1)n\times(p+1) design with an intercept first. Rows are observations. The code object X in the conditional-regression example represents X+X_+.
ΣX\Sigma_X, ΩX\Omega_X Population predictor covariance and precision, ΩX=ΣX−1\Omega_X=\Sigma_X^{-1} when ΣX\Sigma_X is positive definite. Both refer to the predictor scale specified with the model.
ĈX\widehat C_X Empirical Gram matrix X𝖳X/nX^\mathsf{T}X/n of centered working predictors. Sample covariance with divisor n−1n-1 is nĈX/(n−1)n\widehat C_X/(n-1). These normalizations are different.
Ω̂X\widehat\Omega_X A design-based estimated precision on the same predictor scale as ĈX\widehat C_X and the correction. It need not be the ordinary inverse of ĈX\widehat C_X, which is singular when p>np>n.
σ2\sigma^2, σ̂2\widehat\sigma^2 Single-outcome error variance and its estimate, in squared response units. Ordinary Gaussian regression uses residual degrees of freedom n−p−1n-p-1; high-dimensional noise estimation requires a separate argument.
β̂db\widehat\beta_{\mathrm{db}}, V̂db\widehat V_{\mathrm{db}} Debiased slope estimate and estimated covariance: V̂db=(σ̂2/n)Ω̂XĈXΩ̂X𝖳\widehat V_{\mathrm{db}}=(\widehat\sigma^2/n)\widehat\Omega_X\widehat C_X\widehat\Omega_X^\mathsf{T}. The covariance is p×pp\times p; its diagonal gives squared standard errors.
Φ\Phi, α\alpha Standard normal CDF and a stated error level. A specialist argument may use α\alpha for a prior shape, defined locally.
λ\lambda, VV Penalty tuning parameter in regularization; Poisson rate in a separately specified count model. In multiplicity, VV counts false discoveries. Neither use is a hazard or the debiased covariance V̂db\widehat V_{\mathrm{db}}.

A hat denotes an estimate that varies across possible samples. Conditional calculations treat the realized design as fixed only under their stated sampling model. Centered penalized formulas contain slopes only; the intercept is fitted separately without a penalty. Predictor rescaling changes coefficient and precision units, so correction and uncertainty calculations use the same working scale. Code uses dot-separated author-defined R names; package APIs retain their own spelling.
