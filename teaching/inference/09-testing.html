Chapter 7. Hypothesis Testing as a Statistical Procedure

A point estimate reports a plausible parameter value, and a confidence set retains a range of values under a coverage procedure. A hypothesis test asks a narrower question: do the observations reject a specified set of parameter values under a rule with a controlled error probability? We return to the Bernoulli count to construct such a rule and check its operating characteristics for every possible sample.

Suppose a scientifically specified reference probability is p0=0.15p_0=0.15. A study records events in n=20n=20 independently sampled individuals. The question is whether their common event probability exceeds that reference. An observed proportion of 0.300.30 is twice the reference, but that ratio alone supplies neither an error guarantee nor an assessment of practical importance. We need to formulate the null, determine what observations count against it, and examine the procedure under both null and alternative distributions. The reference value is illustrative; it is not a clinical treatment threshold.

We first derive an exact procedure in the Bernoulli model. Approximation can then be evaluated against its actual rejection probability, using the confidence-set and likelihood calculations from Chapter 6.

7.1 A testing rule and its error probabilities

Retain X1,…,Xn∼iidBernoulli(p)X_1,\ldots,X_n\stackrel{\mathrm{iid}}\sim\operatorname{Bernoulli}(p), K=∑iXiK=\sum_iX_i, and p̂=K/n\widehat p=K/n. The hypotheses are H0:p≤p0,H1:p>p0.H_0:p\le p_0,\qquad H_1:p>p_0. \label{i9-hypotheses}(7.1) The null is composite: it contains every probability at or below the reference. An event is encoded by Xi=1X_i=1, so larger counts provide evidence in the stated alternative direction. Reversing the encoding would require reversing the rejection rule, not merely reusing its numerical cutoff.

A test is a function ϕ(X)∈[0,1]\phi(X)\in[0,1]. It gives the conditional probability of rejection at the observed sample. A nonrandomized test has values zero and one; a randomized test also uses an independent random device when its value lies strictly between them. Its power function is βϕ(p)=𝔼p{ϕ(X)},size(ϕ)=supp≤p0βϕ(p).\beta_\phi(p)=\mathbb{E}_p\{\phi(X)\},\qquad \operatorname{size}(\phi)=\sup_{p\le p_0}\beta_\phi(p). \label{i9-power-size}(7.2) We call it level α\alpha if its size is at most α\alpha. Size is the actual worst-case rejection probability under the null; level is an upper bound promised by the procedure. At an alternative value, βϕ(p)\beta_\phi(p) is power and 1−βϕ(p)1-\beta_\phi(p) is the probability of failing to reject. At a null value, rejection is a type I error. These are probabilities over repeated entire experiments, not probabilities assigned to the truth of the observed hypothesis.

The model also states what is repeated. The sample size is fixed in advance, the observations are independent, and they share one event probability. Dependence, unequal risks, outcome-selected sampling, or optional stopping changes the count distribution. A small nominal tail probability computed from the wrong distribution cannot repair those changes. Nor does a one-sample test of a proportion establish that an exposure caused the events. The inferential target here is one population probability under a sampling model.

Failure to reject is a procedural outcome, rather than proof that p≤p0p\le p_0. Alternatives near p0p_0 can be difficult to distinguish at this sample size. Conversely, a sufficiently large sample can detect a scientifically negligible increase. A useful report therefore combines the estimate, a compatible uncertainty assessment, the prespecified testing question, and the operating characteristics relevant to meaningful alternatives. The test should not replace the scientific question with a binary label.

7.2 Exact calibration by enumerating the count

Consider the upper-tail rule ϕc(K)=𝟏{K≥c}\phi_c(K)=\mathbf{1}\{K\ge c\}. Its rejection probability is βc(p)=∑k=cn(nk)pk(1−p)n−k.\beta_c(p)=\sum_{k=c}^{n}\binom nk p^k(1-p)^{n-k}. \label{i9-upper-power}(7.3) The expression is exact for every pp. To show that its largest null probability occurs at p0p_0, use independent Ui∼Uniform(0,1)U_i\sim\operatorname{Uniform}(0,1) and construct Xi(p)=𝟏{Ui≤p}X_i(p)=\mathbf{1}\{U_i\le p\}. For each realized vector of uniforms, K(p)K(p) cannot decrease when pp increases. Hence 𝟏{K(p)≥c}\mathbf{1}\{K(p)\ge c\} and its expectation are nondecreasing. This coupling argument establishes the composite-null calibration without differentiating a long binomial sum.

Choose the smallest integer cutoff with an acceptable tail: cα=min{c∈{0,…,n+1}:ℙp0(K≥c)≤α}.c_\alpha=\min\{c\in\{0,\ldots,n+1\}:\mathbb{P}_{p_0}(K\ge c)\le\alpha\}. \label{i9-cutoff}(7.4) The value n+1n+1 describes never rejecting, so the set is never empty. For n=20n=20, p0=0.15p_0=0.15, and α=0.05\alpha=0.05, the cutoff is 77. Its size is 0.021935100.02193510. Reducing the cutoff to 66 would give size 0.067307970.06730797, exceeding the promised level. No rounding to “about five percent” makes that latter rule a level-0.050.05 test.

This gap is a consequence of discreteness. A nonrandomized upper-tail rule can only choose among a finite set of rejection probabilities. For the conservative rule, power at p=0.30p=0.30 is 0.391990190.39199019; power at p=0.40p=0.40 is 0.749989330.74998933. Thus the observed K=6K=6, although twice the reference in proportion, does not reject with the exact level-0.050.05 rule. The correct interpretation is that this count does not pass the prespecified rejection criterion. It does not assert equality of probabilities or absence of a meaningful effect.

upper.test <- function(n, p0, alpha) {
  k <- 0:n
  mass <- dbinom(k, n, p0)
  tails <- c(pbinom(k - 1, n, p0, lower.tail = FALSE), 0)
  c <- which(tails <= alpha)[1] - 1L
  boundary <- c - 1L
  gamma <- if (boundary >= 0L) (alpha - tails[c + 1L]) / mass[boundary + 1L] else 0
  stopifnot(gamma >= -1e-12, gamma <= 1 + 1e-12)
  phi <- as.numeric(k >= c)
  if (boundary >= 0L) phi[boundary + 1L] <- gamma
  list(c = c, boundary = boundary, gamma = gamma,
       size = tails[c + 1L], phi = phi)
}
test <- upper.test(n, p0, alpha)

7.3 Why likelihood ratios select the upper tail

A valid level bound does not by itself imply good discrimination. To compare procedures, first fix a simple alternative p1>p0p_1>p_0. The ratio of count probabilities is fp1(k)fp0(k)=(1−p11−p0)n{p1(1−p0)p0(1−p1)}k.\frac{f_{p_1}(k)}{f_{p_0}(k)} =\left(\frac{1-p_1}{1-p_0}\right)^n \left\{\frac{p_1(1-p_0)}{p_0(1-p_1)}\right\}^{k}. \label{i9-mlr}(7.5) For 0<p0<p1<10<p_0<p_1<1, the term in braces exceeds one. Therefore larger counts have larger alternative-to-null likelihood ratios. The count orders observations by how strongly they distinguish these two distributions.

The Neyman–Pearson argument turns that ordering into an optimality statement. Let f0,f1f_0,f_1 be two densities with respect to a common measure. Suppose a rule ϕ*\phi^* rejects where f1>af0f_1>af_0, does not reject where f1<af0f_1<af_0, and may randomize on equality, with 𝔼0ϕ*=α\mathbb{E}_0\phi^*=\alpha. For any competitor ϕ\phi satisfying 𝔼0ϕ≤α\mathbb{E}_0\phi\le\alpha, 𝔼1(ϕ*−ϕ)=∫(ϕ*−ϕ)(f1−af0)+a{𝔼0ϕ*−𝔼0ϕ}≥0.\begin{aligned} \mathbb{E}_1(\phi^*-\phi) &=\int(\phi^*-\phi)(f_1-af_0) +a\{\mathbb{E}_0\phi^*-\mathbb{E}_0\phi\}\\ &\ge0. \label{i9-np-proof} \end{aligned}(7.6) In the first integral the factors have the same sign: where the likelihood ratio is large, ϕ*=1\phi^*=1; where it is small, ϕ*=0\phi^*=0. The second term is nonnegative by the level constraint and a≥0a\ge0. Consequently ϕ*\phi^* has at least as much power as any level-α\alpha competitor for the chosen simple alternative. This proof compares complete procedures; it is not a claim that a large likelihood ratio makes the null have a small posterior probability.

For the Bernoulli problem, every alternative p1>p0p_1>p_0 gives the same ordering in (7.5). A size-α\alpha upper-tail test with suitable boundary randomization is therefore most powerful for each such alternative simultaneously. Its monotone power also makes it level α\alpha over the whole composite null. This yields a uniformly most powerful test for (7.1), within the class of tests that permits randomization.

The count loses no information for this comparison. Conditional on K=kK=k, every binary sequence with that count has probability 1/(nk)1/\binom nk, independent of pp. Replacing any sample-based rule by 𝔼{ϕ(X)∣K}\mathbb{E}\{\phi(X)\mid K\} preserves its rejection probability at every pp. This is the testing analogue of conditioning on a sufficient statistic. It also reveals that seemingly nonrandomized choices among equal-count sequences can act as partial rejection after conditioning. We should not label an integer cutoff uniformly most powerful at a larger nominal level merely because we chose not to randomize.

7.4 Boundary randomization and honest power comparisons

Boundary randomization uses the remaining type I error allowance. Reject at K≥7K\ge7, reject with probability γ\gamma at K=6K=6, and otherwise do not reject. Choose γ=α−ℙp0(K≥7)ℙp0(K=6)=0.61853916.\gamma=\frac{\alpha-\mathbb{P}_{p_0}(K\ge7)}{\mathbb{P}_{p_0}(K=6)} =0.61853916. \label{i9-randomization}(7.7) Then 𝔼p0ϕ=α\mathbb{E}_{p_0}\phi=\alpha exactly and βrand(p)=ℙp(K≥7)+γℙp(K=6).\beta_{\mathrm{rand}}(p)=\mathbb{P}_p(K\ge7)+\gamma\mathbb{P}_p(K=6). \label{i9-random-power}(7.8) Because the rejection function is nondecreasing in KK, the coupling argument still controls the composite null. At p=0.30p=0.30, power increases from 0.391990190.39199019 to 0.510526400.51052640; at p=0.40p=0.40 it increases from 0.749989330.74998933 to 0.826942840.82694284.

Randomizing a substantive decision may be unappealing. Its value here is conceptual: it separates the statistical cost of discreteness from the shape of the best rejection ordering. The conservative rule remains valid and can be chosen for transparency. At its achieved size α*=0.02193510\alpha_*=0.02193510, it is a most powerful test against every higher-probability alternative. At nominal level 0.050.05, the randomized procedure has a larger allowance and can improve power. Comparing power without reporting achieved size would confound those facts.

The right panel illustrates the design problem. We must specify an alternative worth detecting before choosing nn; “eighty percent power” is incomplete without that alternative, the rejection rule, and the level. Under discrete nonrandomized tests, increasing nn can occasionally move an integer cutoff enough to reduce power locally. Such irregularities are calibration effects, rather than evidence that information in an additional independent observation is intrinsically harmful. A procedure with more observations can always ignore them, but a particular automatically selected cutoff need not preserve every pointwise comparison.

A fixed experiment cannot sharply separate probabilities immediately on opposite sides of the reference. For any count-based test, randomized or not, its power is a finite polynomial in pp and hence is continuous. In particular, limp↓p0βϕ(p)=βϕ(p0)≤α.\lim_{p\downarrow p_0}\beta_\phi(p)=\beta_\phi(p_0)\le\alpha. \label{i9-local-continuity}(7.9) Thus a level-0.050.05 test cannot have power 0.800.80 uniformly over all p>p0p>p_0 at a fixed finite sample size. This is a structural limit rather than a defect of the chosen method. The practical design question needs a separation that matters scientifically, such as detecting p=0.30p=0.30 against the reference 0.150.15. A prespecified interval of meaningful alternatives can also be examined rather than one convenient value. In either case, low power near the null boundary explains why a nonrejection is weak evidence for a broad claim of equivalence. An equivalence or noninferiority question requires its own hypotheses and scientifically justified margin; it is not obtained by reversing the verbal meaning of an ordinary nonrejection.

At a given null boundary, greater power under alternatives should be examined together with the permitted null rejection probability. Moving a cutoff changes the procedure and its operating characteristics.

7.5 A p-value is a calibrated function of the data

For the upper-tail ordering define the exact p-value Pexact(k)=ℙp0(K≥k)=∑j=kn(nj)p0j(1−p0)n−j.P_{\mathrm{exact}}(k)=\mathbb{P}_{p_0}(K\ge k) =\sum_{j=k}^n\binom njp_0^j(1-p_0)^{n-j}. \label{i9-exact-p}(7.10) It is the smallest level at which a nonrandomized upper-tail rule would reject the observed count, with rejection at equality. At K=6K=6 it equals 0.067307970.06730797. Once the count is observed, this is a fixed number. Before observation, Pexact(K)P_{\mathrm{exact}}(K) is a random variable whose null distribution supplies its calibration.

Specifically, for every p≤p0p\le p_0 and u∈[0,1]u\in[0,1], ℙp{Pexact(K)≤u}≤u.\mathbb{P}_p\{P_{\mathrm{exact}}(K)\le u\}\le u. \label{i9-superuniform}(7.11) To prove this, note that the p-value decreases with kk. Its values at or below uu, if any, form an upper tail K≥cK\ge c. The probability of that tail at p0p_0 is Pexact(c)≤uP_{\mathrm{exact}}(c)\le u, and coupling bounds the probability at every smaller pp. This property is sometimes called super-uniformity. Discreteness makes the inequality strict for many uu; an exact p-value need not have a continuous uniform null distribution.

There is a direct bridge to confidence sets. For a family of level-α\alpha tests indexed by a candidate parameter pp, collect the candidates not rejected at the realized data. If C(X)C(X) is that set, then under the true pp, the event p∉C(X)p\notin C(X) is exactly rejection of that true candidate. Consequently ℙp{p∈C(X)}≥1−α\mathbb{P}_p\{p\in C(X)\}\ge1-\alpha. This is the inversion principle behind the score intervals in Chapter 6. It transfers an error statement only when the entire family of tests has the claimed calibration. Inverting an approximate test does not manufacture exact coverage. For directional tests the resulting set is typically one-sided, and equality conventions at a discrete tail boundary should be stated rather than hidden by decimal rounding. The bridge connects testing and estimation without making them identical reporting tasks: the set retains the range of candidates, while a single test supplies one prespecified comparison.

The definition does not give ℙ(H0∣X)\mathbb{P}(H_0\mid X), the chance that the result was “caused by randomness,” or the chance that replication will fail. No prior over probabilities has been supplied by a p-value calculation. If we separately adopt a Beta(1,1)\operatorname{Beta}(1,1) prior, the posterior at K=6K=6 is Beta(7,15)\operatorname{Beta}(7,15) and ℙ(p≤0.15∣K=6)=0.02874103\mathbb{P}(p\le0.15\mid K=6)=0.02874103. That is a different calculation with an additional modeling choice, not a reinterpretation of the exact tail. Chapter 8 derives this conditioning calculation and examines its interpretation. The p-value also does not give the probability of the observed count alone: the tail includes outcomes judged at least as inconsistent in the prespecified direction. Different alternative directions and different orderings can produce different valid p-values. In particular, simply doubling a one-sided number is not a universal definition of an exact two-sided test in a discrete asymmetric model.

From first principles

For the observed K=6K=6 out of twenty, enumerate the specified upper count tail. The code makes both the sample states and the null probabilities visible:

Preselection is part of the calibration. If two independent studies both use a rule with achieved size α*\alpha_*, rejecting whenever either rejects has size 1−(1−α*)21-(1-\alpha_*)^2 under their common boundary null. For our conservative rule this is approximately 0.043389050.04338905, exceeding its single-study size. Selecting among more outcomes or analyses changes the procedure even when only one final p-value is printed. Dependence changes this particular formula, but does not justify ignoring selection. Similarly, continuing recruitment until the ordinary fixed-nn p-value crosses 0.050.05 requires a sequentially valid design; (7.11) alone is not such a guarantee.

7.6 Score, Wald, and likelihood ratio: an approximation audit

Exact enumeration has shown which counts the calibrated rule rejects. We now compare that benchmark with the large-sample constructions developed in Chapter 5 and Chapter 6. The binomial log likelihood is ℓ(p)=Klogp+(n−K)log(1−p)\ell(p)=K\log p+(n-K)\log(1-p), up to an additive constant. For the point null p=p0p=p_0 in the interior, the signed score and Wald statistics are ZS=p̂−p0p0(1−p0)/n,ZW=p̂−p0p̂(1−p̂)/n.Z_S=\frac{\widehat p-p_0}{\sqrt{p_0(1-p_0)/n}},\qquad Z_W=\frac{\widehat p-p_0}{\sqrt{\widehat p(1-\widehat p)/n}}. \label{i9-score-wald}(7.12) The score divides the score at the null by its null standard deviation; the displayed simplification uses the Bernoulli information. The Wald statistic instead standardizes the fitted estimate using a fitted variance. Both compare with a standard normal reference only under the regular large-sample conditions developed in Chapter 6. They are not algebraically equal at a finite count.

The unrestricted likelihood-ratio deviance is D=2n{p̂logp̂p0+(1−p̂)log1−p̂1−p0},D=2n\left\{\widehat p\log\frac{\widehat p}{p_0} +(1-\widehat p)\log\frac{1-\widehat p}{1-p_0}\right\}, \label{i9-deviance}(7.13) with 0log0=00\log0=0. A signed-root version is R=sign(p̂−p0)DR=\operatorname{sign}(\widehat p-p_0)\sqrt D. For a directional alternative, compare RR with a normal upper-tail critical value. The constrained likelihood-ratio statistic for p≤p0p\le p_0 equals zero when p̂≤p0\widehat p\le p_0 and equals DD above it. Its boundary-null limit is not an unrestricted two-sided χ12\chi^2_1 law; the signed-root formulation here makes the direction explicit. We do not import a two-sided reference cutoff into a one-sided test.

At K=6K=6, ZS=1.87867287Z_S=1.87867287, ZW=1.46385011Z_W=1.46385011, and R=1.69746804R=1.69746804. The corresponding normal upper-tail p-values are 0.030144590.03014459, 0.071617450.07161745, and 0.044804100.04480410. Two reject at nominal 0.050.05 and one does not. That disagreement is understandable: the numerator is the same for score and Wald, but at p̂=0.30\widehat p=0.30 the fitted variance is larger than the null variance. The deviance summarizes a likelihood decrease rather than a squared distance using either single denominator.

Exact continuous calibration is possible when the model supplies it. For independent normal observations with known variance, n(Y¯−μ0)/σ\sqrt n(\overline Y-\mu_0)/\sigma is standard normal at the null boundary at every sample size. At p̂=0\widehat p=0 or 11, the Wald denominator vanishes. The script uses limiting signs to define a complete comparison rule at those endpoints; it does not call a zero standard error valid uncertainty. At the null boundary p0=0p_0=0, a stronger failure occurs: K=0K=0 with certainty under the null, while any observed event is impossible under that model. The rule rejecting when K≥1K\ge1 has size zero and power 1−(1−p)n1-(1-p)^n. Normal score denominators and interior information arguments do not apply. Boundary problems need their own probability calculations.

7.7 From a tail calculation to a scientific interpretation

The calculations enumerate all count outcomes. A useful computational check compares the randomized rule’s power with other rejection vectors constrained to have null rejection probability at most α\alpha. The code below constructs such competitors and compares their power at several alternatives. It illustrates the optimization problem behind Neyman–Pearson; the inequality proved earlier establishes optimality for all competitors, including those omitted from a finite numerical comparison.

This excerpt shows a step inside the preceding complete R example; it uses that block’s data and setup.

# Monotone power; randomized threshold improves upon its conservative version.
for (nn in c(20L,40L,80L)) for (aa in c(.01,.05,.10)) {
  d <- operating[operating$n == nn & operating$alpha == aa, ]
  stopifnot(all(diff(d$conservative.power) >= -1e-12),
    all(diff(d$randomized.power) >= -1e-12),
    all(d$randomized.power >= d$conservative.power - 1e-12))
}
# NP inequality checked against many arbitrary randomized tests with level <=alpha.
set.seed(602917)
for (p1 in c(.20,.30,.50,.80)) {
  alt <- dbinom(k, n, p1)
  for (i in seq_len(1000L)) {
    candidate <- runif(n+1)
    candidate <- candidate*min(1, alpha/sum(null.mass*candidate))
    stopifnot(sum(alt*test$phi) >= sum(alt*candidate)-1e-12)
  }
}

The observed proportion is 0.300.30, but the score-normal tail calculation does not assign a probability to the hypothesis that p≤0.15p\le0.15. It describes a reference tail under the null model. We also cannot select a test merely because it gives the smaller p-value and then use that test’s original calibration without accounting for the selection. Here exact enumeration shows that using the null variance in a normal-reference score test does not give an exact five-percent test.

To interpret the result, we state the prespecified direction and sampling model, calculate the exact count tail, and distinguish approximation from finite-sample guarantees. For this experiment, the exact nonrandomized level-0.050.05 upper-tail test does not reject at K=6K=6; its p-value is 0.06730.0673 and its achieved size is 0.02190.0219. The point estimate remains 0.300.30. That uncertainty matters to scientific interpretation, but no calculation here turns rejection into a treatment recommendation. Chapter 4 already showed why the loss of a scientific action must be specified separately from estimation quality. Here type I error control supplies another distinct procedural target.
